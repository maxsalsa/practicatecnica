# Practica Tecnica CR (practicatecnica.com) - Argon Edition

Plataforma web educativa y PWA Offline-First construida en React + Vite + Tailwind CSS utilizando exclusivamente JavaScript (.jsx) bajo el sistema de diseno Argon.

## Flujo Rapido de Trabajo (Cero Creditos)
Usa el alias configurado para agregar, confirmar y subir en un solo paso:
    git up "feat: actualizacion de componentes"

## Comandos Locales
    npm install
    npm run dev
    npm run build
