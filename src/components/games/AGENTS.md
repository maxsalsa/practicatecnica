# Game modules
- Road circuits use deterministic grid maneuvers and owner-scoped recreational sessions, with personal bests per circuit/vehicle; they never generate academic scores or public student rankings.
- Road progression unlocks steps per vehicle in band-major order from saved personal bests only, so unlocks survive reloads and never depend on other students' data.
- Classic recreational games (tic-tac-toe, connect four, siete y media, school mystery) use pure logic in src/lib/classic-games.ts and local state only; they never award academic scores.
